# ASEI Hardware Repository

This directory contains the physical schematics, Bill of Materials (BOM), and wiring diagrams for the Adaptive Somato-Environmental Interface (ASEI)[cite: 2].

## V1.0 MVP (The Smart Mug Proxy)
For the Build in Public hackathon, the hardware is a simplified proxy bridging physical touch to the web dashboard via USB Serial[cite: 2]. 
*   **MCU:** Arduino Uno/Nano
*   **Trigger:** Capacitive touch simulated via a momentary push button[cite: 2].
*   **Actuator:** Simulated via PWM LED or small 5V DC Motor[cite: 2].

## V3.0 Roadmap (Subdermal AIMD)
The ultimate hardware form factor is an Active Implantable Medical Device (AIMD) operating without an onboard battery[cite: 2]. 
*   **Form Factor:** 18 mm × 4.2 mm × 1.8 mm flexible polyimide PCB[cite: 2].
*   **Encapsulation:** Grade 5 Titanium capsule with a sapphire window, or Parylene-C over medical-grade PDMS[cite: 2].
*   **Electrodes:** Nano-porous TiN or PEDOT:PSS conductive hydrogel coatings to prevent fibrotic encapsulation[cite: 2].
